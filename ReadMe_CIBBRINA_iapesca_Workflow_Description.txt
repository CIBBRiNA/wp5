
CIBBRINA standardized workflow:

Part 1
Create a Random forrest model using the {IAPESCA} package, from annotated data, where Setting/ Hauling is known
Test / Configure the model

Part 2
Apply the Random Forest model on positions data e.g. raw AIS data. to determine fishing effort by vessel

Part 3
Aggregate the fishing effort to the CIBBRINA data format in different aggregation levels
